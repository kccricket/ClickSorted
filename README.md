# ClickSorted

ClickSorted is a modern, Paper-only Bukkit plugin which makes it very easy for players to sort their inventories (player/chest/dispenser) with a single or double click of the mouse. Players can sort by item ID, item name, switch between single- and double-clicking, or disable sorting entirely, all on a per-player basis and without needing any commands; it's all done with mouse clicks in inventory windows.

Originally by Des Herriott, now modernized for Paper API.

## Installation

Copy ClickSorted.jar into your plugins/ folder.  Restart/reload your server.  Done.

## Building

1) Download ClickSorted: "git clone https://github.com/kccricket/clicksort.git"

2) Build ClickSorted: `./gradlew clean build`

This should give you a copy of ClickSorted.jar under the build/libs directory.
