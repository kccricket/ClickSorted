# Development

## Building from source

```bash
git clone https://github.com/kccricket/clicksorted.git
cd clicksorted
./gradlew clean build
```

The output JAR will be at `build/libs/clicksorted-<version>.jar`.

## Running the test suite

```bash
./gradlew clean test
```
